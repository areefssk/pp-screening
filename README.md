# PP Screening · ระบบลงผลและสรุปผลงาน PP Fee Schedule

เว็บแอปสำหรับลงจำนวนผู้รับบริการคัดกรองรายวัน ระบบคิดยอดเงินจากราคากลางให้เอง และแสดงผลเป็นแดชบอร์ดตามปีงบประมาณ (ต.ค.–ก.ย.)
ใช้ได้ทั้งมือถือและคอมพิวเตอร์ ติดตั้งลงหน้าจอโฮมมือถือได้ (PWA)

- **หน้าเว็บ**: GitHub Pages (ไฟล์ในโฟลเดอร์นี้)
- **หลังบ้าน**: Google Sheet + Apps Script (`apps-script/Code.gs`)
- **ข้อมูลตั้งต้น**: `PP_Screening_ฐานข้อมูล.xlsx` มีรายการกับราคาจริง 18 รายการ และยอดเดิม ม.ค.–26 พ.ย. 2569 แล้ว (ไฟล์นี้แนบมาแยก **ห้ามอัปโหลดขึ้น GitHub**)

## ติดตั้ง (ทำครั้งเดียว ใช้เวลาประมาณ 20 นาที บนคอมพิวเตอร์)

### ขั้นที่ 1 · สร้างฐานข้อมูลใน Google Sheet
1. เปิด Google Drive แล้วอัปโหลด `PP_Screening_ฐานข้อมูล.xlsx` (แนะนำให้ใช้บัญชี Google ของหน่วยงาน)
2. ดับเบิลคลิกเปิดไฟล์ แล้วไปที่ **ไฟล์ → บันทึกเป็น Google ชีต** จะได้ไฟล์ Google Sheet ใหม่ จากนั้นใช้ไฟล์นี้เป็นหลัก
3. ในไฟล์ Google Sheet ไปที่ **ส่วนขยาย → Apps Script**
4. ลบโค้ดเดิมออกให้หมด วางโค้ดทั้งหมดจาก `apps-script/Code.gs` แล้วกด 💾 บันทึก
5. กลับมาที่ชีตแล้วรีเฟรช จะมีเมนู **ระบบ PP** ให้กด **ติดตั้ง / ตรวจโครงสร้างชีต**
   - ครั้งแรก Google จะขออนุญาต ให้กด อนุญาต → ขั้นสูง → ไปที่โปรเจกต์ → อนุญาต
6. กดเมนู **ระบบ PP → สร้างแท็บสรุปทุกเดือนที่มีข้อมูล** จะได้แท็บ "สรุป ม.ค.69" … "สรุป พ.ย.69" ในหน้าตาแบบเดิม
7. กดเมนู **ระบบ PP → เปิดสำรองข้อมูลอัตโนมัติทุกคืน**

### ขั้นที่ 2 · ตั้งผู้ใช้
- ไปที่แท็บ **ผู้ใช้** แล้วเพิ่มแถวละ 1 คน ได้แก่ ชื่อ, PIN (ตัวเลข 4–6 หลัก), สิทธิ์ (ผู้ดูแล/ผู้ใช้), เปิดใช้ = TRUE
- PIN ที่พิมพ์ไว้จะถูกเข้ารหัสอัตโนมัติตอนที่คนนั้นล็อกอินครั้งแรก ถ้าลืม PIN ให้ผู้ดูแลพิมพ์ PIN ใหม่ทับในช่องนั้นได้เลย
- **เปลี่ยน PIN 1234 ของผู้ดูแลระบบ** ทันทีหลังล็อกอินครั้งแรก (ในแอป: กดชื่อ → เปลี่ยน PIN)

### ขั้นที่ 3 · เปิด API
1. ใน Apps Script กด **Deploy → New deployment → ⚙︎ เลือก Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
2. กด Deploy แล้วคัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)
3. ทดสอบโดยเปิด URL นั้นในเบราว์เซอร์ ถ้าเห็น `PP Screening API v3 พร้อมใช้งาน` แปลว่าใช้ได้

### ขั้นที่ 4 · ขึ้นหน้าเว็บบน GitHub
1. เปิดไฟล์ `config.js` แล้ววาง URL จากขั้นที่ 3 ลงใน `API_URL: '...'`
2. สร้าง repository ใหม่บน GitHub (Public) แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ ยกเว้นไฟล์ xlsx
3. ไปที่ **Settings → Pages → Branch: `main` / `(root)` → Save**
4. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/` แล้วส่งลิงก์นี้ให้ทีม

### ขั้นที่ 5 · ติดตั้งลงมือถือ
- **Android (Chrome)**: เปิดลิงก์แล้วกดปุ่ม **ติดตั้ง** ที่ขึ้นในแอป
- **iPhone (Safari)**: กดปุ่มแชร์ ⬆︎ → **เพิ่มไปยังหน้าจอโฮม**

## งานประจำของผู้ดูแล
- **ปิดยอดเดือน**: หลังส่งรายงานแล้ว ไปที่แท็บ `ตั้งค่าระบบ` แล้วใส่วันสุดท้ายของเดือนในช่อง "ปิดยอดถึงวันที่" เช่น `2026-11-30`
- **เปลี่ยนราคา**: ห้ามแก้ราคาในแถวเดิม ให้ใส่วันสิ้นสุดในแถวเดิม แล้วเพิ่มแถวใหม่ที่ใช้ **รหัสใหม่** (เช่น `HIV2`) พร้อมวันเริ่มใช้ ยอดเก่าจะคงราคาเดิม
- **เพิ่มรายการใหม่**: เพิ่มแถวในแท็บ `ตั้งค่ารายการ` โดยตั้งรหัสสั้น ๆ เป็นภาษาอังกฤษที่ไม่ซ้ำกับรายการอื่น แล้วกดเมนู **ระบบ PP → ล้างแคชแดชบอร์ด**
- **ห้ามแก้แท็บ `ข้อมูลดิบ` และ `ประวัติการแก้ไข` ด้วยมือ** ให้แก้ผ่านแอปเท่านั้น ประวัติการแก้ไขจะได้ครบ
- แท็บ `สรุป …` ระบบสร้างใหม่ทุกครั้งที่บันทึก จึงไม่ควรแก้ในแท็บนั้นด้วยมือ

## เมื่อแก้โค้ด
- แก้ `Code.gs` แล้วต้องกด **Deploy → Manage deployments → ✏️ → Version: New version → Deploy** URL จะยังเท่าเดิม
- แก้หน้าเว็บแล้ว ให้เปลี่ยนเลข `CACHE` ใน `sw.js` (เช่น `v3` เป็น `v4`) มือถือที่ติดตั้งแอปไว้จะขึ้นปุ่ม "อัปเดต"

## ทดลองโดยไม่แตะข้อมูลจริง
เติม `?demo=1` ท้ายลิงก์ แอปจะใช้ข้อมูลสมมติ ล็อกอินด้วยชื่อไหนก็ได้และ PIN อะไรก็ได้

## ความปลอดภัย
- ระบบเก็บเฉพาะ **จำนวนคน** ห้ามใส่ชื่อหรือเลขบัตรผู้ป่วยในหมายเหตุ ระบบจะปฏิเสธถ้าเจอตัวเลข 13 หลัก
- PIN เก็บแบบเข้ารหัส ถ้าใส่ผิด 5 ครั้งจะถูกล็อก 15 นาที และการเข้าสู่ระบบแต่ละครั้งมีอายุ 8 ชั่วโมง
- อย่าแชร์ไฟล์ Google Sheet ให้คนทั่วไป ทุกคนให้ใช้งานผ่านแอป
